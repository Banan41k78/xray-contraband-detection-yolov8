# Environment Requirements

Before running the pipeline, make sure everything listed below is installed on your machine.

---

## Minimum Requirements

| Component | Version | Why |
|---|---|---|
| **Python** | ≥ 3.9 | syntax, `pathlib`, `ultralytics` |
| **pip** | ≥ 21.0 | package installation |
| **git** | any | cloning the repository |
| **OS** | Linux / macOS / Windows 10+ | cross-platform |
| **RAM** | ≥ 4 GB | model loading + inference |
| **Disk** | ≥ 1 GB free | weights (~130 MB) + predictions |

---

## Python Dependencies

Install everything with a single command:

```bash
pip install -r requirements.txt
